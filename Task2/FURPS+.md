# FURPS+ таблица требований

## Контекст

Таблица объединяет требования для двух направлений:

1. MVP и целевое развитие онлайн-депозитов.
2. Онлайн-заявка на кредит на сайте и в интернет-банке.

В таблицу включены архитектурно значимые требования, а также несколько дополнительных требований, которые не сформулированы напрямую в кейсе, но влияют на решение.

## Вывод

По результатам анализа есть четыре ключевых архитектурных акцента:

1. Новые цифровые процессы нельзя строить вокруг прямых вызовов в АБС и тем более вокруг интеграции по БД из интернет-банка.
2. Для депозитного направления критично вынести ставки из Excel в отдельный управляемый контур.
3. Для кредитного направления критично создать единый реестр заявок и новый путь в кредитный конвейер без суточной задержки.
4. Все новые компоненты должны развиваться силами банка и минимально зависеть от подрядчиков и устаревшего ядра интернет-банка.
