# Крупные задачи по системам

## 1. Платформа ставок

1. Реализовать мастер-справочник ставок и правила публикации версий.
2. Добавить внутренний `Rates API` для потребителей внутри банка.
3. Реализовать журнал публикации, доставки и повторных попыток.
4. Реализовать экспорт ставок во внешний файл для партнёрского кол-центра.
5. Настроить роли доступа для сотрудников, публикующих ставки.

## 2. Сайт банка

1. Перевести витрину депозитных ставок на получение данных из `Rates API`.
2. Согласовать формат отображения публичных условий и даты актуальности.
3. Добавить обработку сценариев временной недоступности API и показ последней успешной версии.

## 3. Интернет-банк

1. Перевести получение депозитных ставок на единый `Rates API`.
2. Убедиться, что отображаемые в интернет-банке ставки согласованы с витриной сайта и с депозитной платформой.
3. Добавить отображение даты обновления и обработку ошибок получения справочных данных.

## 4. Система кол-центра банка

1. Реализовать адаптер загрузки ставок из `Rates API`.
2. Добавить локальный кэш и механизм обновления без остановки работы операторов.
3. Встроить виджет ставок в рабочее место оператора.
4. Добавить отображение версии набора ставок и времени последнего обновления.

## 5. Партнёрский кол-центр

1. Согласовать формат файла, состав полей и правила обработки обновлений.
2. Настроить приём файлов и загрузку ставок во внутренние скрипты или справочник партнёра.
3. Согласовать процесс обработки ошибок доставки и ручного подтверждения получения.

## 6. Интеграционный контур банка

1. Настроить файловый канал обмена с партнёрским кол-центром.
2. Реализовать контроль доставки, повторные попытки и журнал обмена.
3. Подготовить эксплуатационные инструкции по разбору сбоев.

## 7. Команда эксплуатации и инфраструктуры

1. Настроить мониторинг `Rates API`, фоновых публикаций и файловых выгрузок.
2. Добавить оповещения по сбоям обновления ставок у внутренних и внешних потребителей.
3. Подготовить резервные регламенты на случай недоставки файлов партнёру.
